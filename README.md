# Trung tâm tiếng Anh TTA
## Giới thiệu
Dự án xây dựng website **Trung tâm tiếng Anh TTA** nhằm hỗ trợ học viên tìm hiểu khóa học và đăng ký học. Website hướng đến trải nghiệm *đơn giản, thuận tiện*.
## Cấu trúc thư mục
| Thư mục | Nội dung |
|---|---|
| `data/` | Lưu trữ dữ liệu học viên và học phí |
| `docs/` | Lưu tài liệu dự án |
| `logs/` | Lưu nhật ký hệ thống |
| `media/` | Lưu hình ảnh và tài nguyên truyền thông |
## Quy trình đăng ký học
1. Tìm hiểu thông tin các khóa học trên website.
2. Chọn khóa học phù hợp và điền thông tin đăng ký.
3. Xác nhận thông tin và hoàn tất đăng ký.
## Lệnh kiểm tra dự án
```powershell
Get-ChildItem -Recurse
```
